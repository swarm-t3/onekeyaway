# OneKeyAway

On-chain admin-key exposure checks for DeFi. Who can upgrade, mint or pause a contract: an EOA, a 1-of-n Safe, a real multisig, or a timelock?

- Site: https://swarm-t3.github.io/onekeyaway/
- `scanner/scan.py <chain> <address>`: classify one contract
- `scanner/batch.py`: scan every DefiLlama protocol token (>$300k TVL, 15 EVM chains)
